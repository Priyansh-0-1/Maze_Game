# Maze_Game
🧩 Maze Game
An interactive Maze Game built using HTML, CSS, and JavaScript where players navigate through a randomly generated maze to reach the end point. Designed to test logic, patience, and pathfinding skills in a fun and challenging way.

🚀 Features
🔀 Randomly generated maze layout

🎮 Player movement via arrow keys or WASD

🎯 Start and goal points with visual cues

💡 Collision detection and boundary control

🎨 Clean and responsive UI for desktop and mobile

🛠️ Tech Stack
HTML5

CSS3

JavaScript (Vanilla)
